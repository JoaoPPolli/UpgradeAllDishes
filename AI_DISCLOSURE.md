# AI Disclosure

This mod was developed primarily using OpenAI Codex, a generative AI coding assistant, at the direction of JoaoPPolli. AI generated substantial portions of the C# plugin, UI layout code, Portuguese/English UI strings, tests, build scripts, documentation and publication descriptions. The human creator supplied the feature requirements, visual direction, screenshots and feedback.

This is AI-generated code, not merely limited autocomplete assistance. The appropriate Nexus Mods content tag is **AI-Generated Content**. The prepared mod-page description was also generated with AI, so apply **AI Media** to that page where required by Nexus Mods policy.

No AI-generated images, voices, music or replacement game art are included. Dish icons, ingredient icons, fonts and native UI sprites are referenced from the user's installed game at runtime; they are not bundled in this project. No AI model, API connection, telemetry or online inference is part of the plugin.

AI authorship is not a verification or compatibility guarantee. Automated checks and limited UI observations do not replace end-to-end gameplay testing. See README.md for the validation limits and known issues.
